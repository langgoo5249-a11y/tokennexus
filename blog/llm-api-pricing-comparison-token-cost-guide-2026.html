大模型 API 价格怎么算？主流模型每百万 Token 价格对比与账单拆解（2026 版）

TokenNexus团队2026-11-21约 12 分钟读完

同一个客服机器人需求，用不同的大模型 API 跑一个月，账单可以从几十美元差到上千美元——差距不是玄学，而是计费规则和选型策略的差别。这篇文章不谈虚的，只做三件事：讲清大模型 API 的计费公式，给出主流模型每百万 Token 的价格对比表，再用一个可以逐行复算的案例把"账单是怎么长出来的"拆开给你看。

先说结论：输出 Token 单价贵、多轮对话历史重复计费、推理模型的思维链也收费，这三件事吃掉了绝大多数人账单里意想不到的部分。看懂它们，比任何"省钱咒语"都管用。

一、大模型 API 计费方式：每百万 Token 单价是唯一锚点

目前几乎所有主流大模型 API（OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问等）都采用同一套计费逻辑：按 Token 用量计费，输入与输出分开计价，官方报价以"每百万 Token（1M tokens）多少美元"标注。Token 是模型处理文本的最小单位，一个英文单词约等于 1.3 个 Token，中文则平均一个字约等于 0.6～0.7 个 Token——中英文的 Token 换算差异直接影响成本，我们在此前的 中文 Token 计量与成本指南里做过详细测算。

月账单的计算公式只有一行：

月成本 =（日均调用次数 × 平均输入Token × 30 ÷ 1,000,000 × 输入单价）
      +（日均调用次数 × 平均输出Token × 30 ÷ 1,000,000 × 输出单价）

注意三个要点：第一，输入输出的单价不同，输出通常贵 3～8 倍，因为生成 Token 需要逐个解码，算力开销远高于并行处理输入；第二，多轮对话的历史消息每次都会重新计入输入 Token，对话轮次越多，这条"隐形复利"越夸张；第三，推理类模型（如 OpenAI o 系列、DeepSeek R1）的思维链 Token 同样计费，有时候甚至超过最终答案的长度。

三、账单拆解：同一个客服机器人，四种方案的月账单

空谈单价没有体感，我们用一个典型场景做完整测算。假设你在做一个智能客服机器人：

  • 日均 5,000 次对话请求，每月按 30 天计；
  • 每次请求平均输入 2,000 Token（含多轮历史和知识库摘要）；
  • 每次请求平均输出 500 Token。

先算总用量：每月输入 Token = 5,000 × 2,000 × 30 = 3 亿（300M）；每月输出 Token = 5,000 × 500 × 30 = 7,500 万（75M）。下面代入四种方案（美元计，人民币按 7.2 估算仅作参考）：

方案计算过程月成本
A：全量旗舰（GPT-5）300M×$1.25÷1M + 75M×$10÷1M = $375 + $750$1,125 ≈ ¥8,100
B：轻量档（Haiku 4.5）300M×$1÷1M + 75M×$5÷1M = $300 + $375$675 ≈ ¥4,860
C：高性价比国产（DeepSeek V3.2，假设 60% 输入缓存命中）120M×$0.28 + 180M×$0.028 + 75M×$0.42 = $33.6 + $5.04 + $31.5约 $70 ≈ ¥505
D：分级路由（70% 简单问题走 GPT-5 mini，30% 复杂走 GPT-5）210M×$0.25 + 52.5M×$2 + 90M×$1.25 + 22.5M×$10 = $52.5 + $105 + $112.5 + $225$495 ≈ ¥3,564

同一个产品需求，账单从 ¥505 到 ¥8,100，相差 16 倍。这不是夸张的营销数字，而是上面公式逐行算出来的结果，你可以拿自己的用量代入验证。方案 C 和 D 之间怎么取舍，取决于业务对回答质量的要求：客服场景里大量问题其实是"查订单、问退货政策"这类模板化需求，把它们路由给便宜模型、只把疑难杂症交给旗舰，就是分级调用的价值。如果你的业务允许异步处理（比如批量生成日报、批量翻译），还可以叠加 Batch API 的官方五折，参考 Batch API 半价实战，方案 D 的成本还能再降一档。

四、四个大多数开发者都忽略的计费细节

1. 输出才是账单大头，别让它"自由发挥"

输出单价是输入的 3～8 倍，而很多应用默认让模型写到自然结束。给 max_tokens 设一个合理上限、要求"答案控制在 200 字以内"、让模型输出结构化 JSON 而不是整段散文，通常能直接砍掉 30% 以上账单。

2. 多轮对话的历史是"重复付费"

第 10 轮对话的输入包含前 9 轮全部内容——你为同一段文字付了 10 次钱。长对话场景务必做历史压缩或滑动窗口截断，配合提示缓存可以把重复部分的成本压到十分之一。

3. 推理模型的思维链也在计费

o 系列、DeepSeek R1 这类推理模型会先生成内部推理过程，这些 Token 同样按输出价收费。数学、代码类复杂任务物有所值，但让推理模型回答"今天天气怎么样"就是纯浪费——又一个该用分级路由的信号。

4. 价格之外还有"结构性费用"

文件存储、图片输入按张计费、工具调用的中间结果都可能产生附加费用。我们在此前的 账单暴涨排查指南里记录过真实案例：一个团队月账单突然翻 4 倍，最后发现是日志系统把失败重试也全量计费了。拿到第一张真实账单后，务必逐项核对。

五、价格不是全部：免费额度与降价时间线同样重要

对比价格时别忽略三件事。其一，多数厂商提供免费额度或免费档（Google AI Studio、GitHub Models、各大聚合平台的免费模型），验证期和小流量阶段可以做到零成本，我们维护了一份持续更新的 AI API 免费额度汇总。其二，大模型 API 的价格曲线整体是快速下探的：同样的能力，每一代新模型的单位价格几乎都在下降，锁死某一家的高价套餐前先看看市场。其三，开源模型自部署没有 Token 单价，但 GPU 成本和运维成本要摊进去算，小流量团队自部署多数情况下反而不划算。

六、选型决策清单

  • 先测用量再谈价格：上线前用小流量跑一周，从响应的 usage 字段统计真实输入输出 Token 分布，代入本文公式；
  • 把输出长度管起来：max_tokens 上限 + 输出格式约束，收益立竿见影；
  • 能缓存的一定缓存：系统提示词、知识库前缀固定下来，享受 1/10 的缓存价；
  • 建立分级路由：模板化请求走轻量模型，复杂任务才请旗舰出场；
  • 异步任务走 Batch：不要求秒回的任务，官方五折是白送的；
  • 每月复盘一次账单：价格在降、用量在涨，静态方案三个月就会过期。

常见问题

每百万 Token 价格到底是什么单位？

官方报价的统一计量方式：每处理 1,000,000 个 Token 收取标价的美元金额。1 百万 Token 约相当于 60～90 万英文单词量级的文本，中文约 50～70 万字，随分词器略有差异。

为什么同一模型在不同平台价格不一样？

官方 API 按官网价结算；云厂商托管版、聚合平台和中转服务会加价或折扣，部分按充值档位浮动。比价时同时看单价、稳定性与合规性，平台对比页有各家的结构化数据。

输入输出为什么要分开计价？

输入是一次性并行计算，输出是逐 Token 自回归解码，后者算力成本数倍于前者，所以输出单价普遍更高，这也是"控制输出长度"能省钱的原因。

有没有官方的账单估算工具？

OpenAI、Anthropic、Google 都在开发者文档中提供了交互式定价估算器或价格计算参考，配合本文第三节的公式，双核对基本可以控制在真实账单 ±10% 以内。
