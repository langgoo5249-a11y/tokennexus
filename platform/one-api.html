One API 注册与API Key获取教程

开始使用 One API API 只需简单几步：

  1. 访问 One API 官网（https://github.com/songquanpeng/one-api），点击注册按钮创建账号
  2. 完成邮箱验证和身份认证，支持手机号快捷注册
  3. 登录控制台，进入 API管理 页面，点击「创建API Key」
  4. 复制并妥善保存 API Key（仅显示一次），配置到您的应用中
  5. 参考官方API文档，配置请求参数，开始调用AI接口
  6. 在监控面板查看API调用量、费用和使用统计
