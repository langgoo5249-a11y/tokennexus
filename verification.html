平台审核与验证标准

TokenNexus 如何确保平台信息的真实性和可靠性

1. 引言

TokenNexus 致力于为用户提供准确、可靠、及时的 AI API 平台信息。我们建立了严格的审核与验证流程，确保平台上展示的每一条信息都经过核实。

本页面详细说明我们的审核标准、验证流程、徽章体系以及数据来源，帮助您理解 TokenNexus 上的信息是如何产生和维护的。

我们的承诺：所有收录的平台信息均经过人工审核验证，价格数据定期更新，用户评价真实可信。

2. 审核流程

每个平台在 TokenNexus 上展示前，都必须经过以下四步审核流程：

1
提交审核
平台信息可通过以下方式提交：
  • 平台官方团队通过"提交平台"功能主动提交
  • 用户通过反馈表单推荐新平台
  • TokenNexus 运营团队主动发现并收录
提交时需提供平台名称、官网链接、API 文档地址、支持模型等基础信息。
2
人工验证
我们的审核团队会对提交的信息进行人工验证：
  • 确认官方网站可正常访问，域名归属正确
  • 验证 API 文档页面是否存在且内容有效
  • 检查平台是否提供真实的 API 服务（非钓鱼或欺诈网站）
  • 验证平台的运营主体和注册信息（如可获取）
3
信息核实
对平台的核心信息进行逐项核实：
  • 价格信息：对比官网定价页面，确认各模型的输入/输出价格
  • 功能特性：核实支持的 API 功能（流式输出、函数调用、嵌入等）
  • 模型列表：确认平台支持的具体模型名称和版本
  • 支付方式：验证支持的支付渠道和结算货币
  • 服务区域：确认平台的服务覆盖范围
4
定期复查
已收录平台会进行持续的维护和更新：
  • 季度全面复查：每季度对所有平台进行一次全面信息核查
  • 价格变动监测：监测各平台价格调整，及时更新数据
  • 可用性监控：定期检查平台官网和 API 的可用状态
  • 用户反馈响应：根据用户反馈及时修正或更新信息

3. 徽章说明

TokenNexus 使用以下徽章来标识平台的审核状态和特性，帮助您快速识别可信平台：

✓
已验证
平台信息经 TokenNexus 人工审核团队确认，官网可访问，API 文档有效，核心数据已核实。
企
企业级
平台支持 SLA（服务等级协议），具备 SOC2 合规认证，符合 GDPR 数据保护要求，适合企业级部署。
●
活跃维护
平台在 30 天内有更新、公告或版本迭代，表明产品处于积极维护和迭代状态。

注意：徽章状态会随时间变化。我们会定期重新评估平台的徽章资格，确保标识的准确性。如果您发现某平台的徽章状态与实际情况不符，欢迎通过页面底部的联系方式反馈。

4. 数据来源说明

TokenNexus 上的平台信息来源于多个渠道，我们根据来源的可靠性对数据进行分级管理：

🌐 官方数据
优先级：最高
直接来源于平台官方网站、官方 API 文档、官方定价页面和官方公告。这是我们最信赖的数据来源，所有核心信息均以官方数据为准。
💬 用户反馈
优先级：高
来自真实用户的使用评价、体验反馈和纠错建议。用户反馈是我们发现信息偏差和获取实际使用体验的重要渠道。
📰 公开信息
优先级：中
来自行业报告、权威媒体报道、学术研究和技术博客等第三方公开信息。此类信息会经过交叉验证后谨慎采用。

数据更新策略：

  • 官方价格变动：通常在发现后 7 个工作日内更新
  • 平台功能更新：在官方发布后的下次季度复查中同步
  • 用户纠错反馈：核实后 3 个工作日内修正
  • 新增平台收录：提交后 5-10 个工作日内完成审核

5. 争议处理

5.1 申请信息修改

  • 发送邮件至 644428571@qq.com，邮件主题注明"【信息修改】平台名称"
  • 在邮件中说明需要修改的具体内容和修改后的正确信息
  • 提供可验证的参考资料链接（如官方定价页、官方公告等）
  • 我们将在 5 个工作日内核实并完成修改

5.2 申请信息下架

  • 发送邮件至 644428571@qq.com，邮件主题注明"【下架申请】平台名称"
  • 说明下架理由（如平台已停止运营、信息涉及侵权等）
  • 提供相关证明材料
  • 我们将在 7 个工作日内审核并回复处理结果

5.3 用户纠错反馈

  • 通过任意页面的反馈入口提交纠错信息
  • 或通过邮件发送至 644428571@qq.com
  • 详细描述问题并提供正确的信息来源
  • 核实后我们将及时修正并向反馈者致谢
